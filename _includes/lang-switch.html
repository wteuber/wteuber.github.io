{%- comment -%} Language pill next to the night mode button (styles in assets/css/lang-switch.css), built to look and behave like it: the pill shows the flag of the page's language with the knob on the left. Hovering previews the other language (its flag fades in and the knob slides right); clicking keeps that state and opens the translation. Included twice by nav.html: next to the night mode button, and in the collapsed menu for narrow screens (the CSS shows one of them). Shown only when the page has a translation (`i18n_alts`, from i18n-alternates.html). With more than two languages it links to the next one in `site.languages` that has a translation. {%- endcomment -%} {%- assign ls_alt = nil -%} {%- for l in site.languages -%} {%- if l != lang and ls_alt == nil -%} {%- assign ls_alt = i18n_alts | where: "lang", l | first -%} {%- endif -%} {%- endfor -%} {%- if ls_alt -%} {%- unless lang_switch_script -%}{%- assign lang_switch_script = true %} {%- endunless -%} {%- endif -%}
